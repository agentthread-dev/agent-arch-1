[워크플로 설계서 v2 — 주간 회의 후속 처리 (첫 판)]
목표    : 주간 회의 뒤 30분쯤 걸리던 후속 정리를 "한 줄 요청 + 확인 10분"으로 줄인다
입력    : meetings/ 에서 파일 이름 기준 가장 최근 2개 (이번 주·지난주). 고른 파일을 먼저 보여 준다
결과물  : followup/<이번 주>.md, reports/weekly-<이번 주>.md

순서와 층 (Skill 셋 + 작업 폴더 — MCP 서버 없음)
 1. 회의록 고르기      — 작업 폴더. 가장 최근 파일이 7일보다 오래됐으면(이번 주 회의록 없음) 멈추고 묻는다
 2. 이번 회의록 정리   — Skill meeting-followup (결정·할 일 표·미결·공유 메일 초안), 할 일마다 근거 줄
 3. 지난주 대조        — 워크플로 Skill 안의 단계. 지난주 할 일과 미결 모두
                         상태: 끝남 / 일부 / 진행 중 / 연기 / 결정됨 / 언급 없음, 애매하면 "확인 필요", 근거 줄 표시
 4. 주간 보고 초안     — Skill weekly-report (2·3의 결과로만)
 5. 점검               — 워크플로 Skill 안의 단계. 아래 '점검'을 스스로 대조하고, 못 고친 것은 "확인 필요"로
 6. 저장               — followup/, reports/. 같은 이름의 파일이 있으면 덮어쓰지 않고 묻는다
 엮기                 — 워크플로 Skill weekly-followup

점검    : 결정·할 일·미결·상태마다 회의록 근거 줄이 있나 / 마감 없는 할 일은 "미정"
          / 상대 마감("이번 주 안에")은 원문 그대로 + 날짜는 "추정" / "언급 없음"·"일부"를 "끝남"으로 쓰지 않음
          / 담당 미정에 사람을 넣지 않음, 미결에 결론·추천을 달지 않음
사람    : 확인 기준표로 10분 확인 (맨 위 "확인 필요" 모음부터), 담당 미정 배정, 미결 결정, 팀에 공유
울타리  : deny Edit(meetings/**) / 연결된 메일·채팅 커넥터는 /mcp에서 끄거나 보내는 도구를 deny
