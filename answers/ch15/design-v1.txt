[워크플로 설계서 v1 — 주간 회의 후속 처리]
목표    : 주간 회의 뒤 30분쯤 걸리던 후속 정리를 "한 줄 요청 + 확인 10분"으로 줄인다
입력    : meetings/이번 주.md, meetings/지난주.md
결과물  : followup/이번 주.md (결정·할 일 표·미결·공유 메일 초안), reports/weekly-이번 주.md

순서와 층
 1. 회의록 가져오기    — MCP 서버 meeting-box를 새로 만든다 (list_meetings, read_meeting)
 2. 이번 회의록 정리   — Skill meeting-followup
 3. 지난주 할 일 대조  — 상태: 끝남·진행 중·언급 없음
 4. 주간 보고 초안     — Skill weekly-report
 5. 저장
 엮기                 — 워크플로 Skill weekly-followup

점검    : 할 일 표의 줄 수 = 회의록의 할 일 수 / 마감 없는 할 일은 "미정" / "언급 없음"을 "끝남"으로 쓰지 않음
멈출 곳 : 이번 주 회의록이 없으면 멈추고 묻는다 / 담당 미정 할 일은 배정하지 않고 사람에게
사람    : 미결 결정, 담당 미정 배정, 팀에 공유
울타리  : deny Edit(meetings/**) — 회의록 원본은 고치지 않는다
첫 판에서 뺀 것: 팀 채널 자동 게시(MCP), 캘린더 등록, 여러 팀 취합
