# 주간 업무 보고서 양식

아래 틀을 그대로 복사해 채운다. 칸 이름과 순서(끝낸 일 → 진행 중 → 다음 주 계획 → 요청 사항)를 바꾸지 않는다.

```
# 주간 업무 보고 ({기간, 예: 11월 첫째 주})
보고자: {이름} / 받는 분: 팀장님

## 1. 끝낸 일
- {업무} — {결과 한 줄}

## 2. 진행 중
- {업무} — 진행률 {메모에 적힌 %}

## 3. 다음 주 계획
- {업무} ({요일이나 날짜가 메모에 있으면 함께})

## 4. 요청 사항
- {팀장님이 결정하거나 도와주셔야 할 일} — {왜 필요한지 한 줄}
```

## 칸별 안내

**1. 끝낸 일**
- 이번 주에 마친 일만 쓴다. 결과가 숫자로 있으면 숫자를 그대로 옮긴다
- 1페이지를 넘으면 이 칸부터 줄인다 (비슷한 일은 한 줄로 묶는다)

**2. 진행 중**
- 업무마다 진행률을 메모에 적힌 대로 붙인다
- 메모에 진행률이 없으면 숫자를 만들지 말고 "진행률 확인 필요"라고 쓴다

**3. 다음 주 계획**
- 메모에 "다음 주"로 적힌 일과, 진행 중인 일 가운데 다음 주에 이어서 할 일을 쓴다
- 메모에 없는 마감일을 정하지 않는다

**4. 요청 사항**
- 결정이 필요하거나 막혀 있는 일을 여기에 모은다. 다른 칸에 흩어 두지 않는다
- 없으면 "없음"이라고 쓴다. 칸을 지우지 않는다
