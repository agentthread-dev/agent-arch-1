[Skill 설계 메모]
이름     : customer-reply
언제     : 고객 문의 메일에 보낼 답장 초안을 써 달라고 할 때
목적     : 회사 정책을 지키면서, 고객이 바로 이해할 수 있는 답장 초안
입력     : 고객 문의 메일 원문 (주문번호가 있으면 함께)
절차     : 문의 유형 파악 → 정책 확인 → 답장 작성 → 점검
출력 형식 : 제목 / 인사 / 답변 본문 / 다음 안내 / 맺음말 + 담당자 메모
확인 기준 : 정책에 없는 약속 금지, 모르는 건 "담당자 확인 필요"로 표시
참고 파일 : 환불·교환·배송 정책 → references/policy.md
