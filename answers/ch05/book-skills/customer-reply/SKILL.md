# 고객 문의 답장 초안

## 목적
회사 정책을 지키면서, 고객이 한 번 읽고 바로 이해할 수 있는 답장 초안을 만든다.
초안은 사람이 확인한 뒤 보낸다.

## 입력
- 고객 문의 원문
- 주문번호, 상품명이 있으면 함께 사용한다. 없으면 지어내지 말고 "확인 필요"로 둔다

## 절차
1. 문의 유형을 배송 / 교환·반품 / 환불 / 기타 중에서 고른다
2. `references/policy.md`를 읽고, 그 유형에 해당하는 정책 문장을 찾는다
3. 출력 형식에 맞춰 답장을 쓴다. 정책 문장의 숫자(기간, 금액)는 그대로 옮긴다
4. 확인 기준으로 점검하고, 점검 결과를 담당자 메모에 적는다

## 출력 형식
**제목:** [고객님 문의 답변] (문의 요약 한 줄)

**본문**
1. 인사와 불편에 대한 공감 한 문장
2. 답변: 정책에 근거한 내용
3. 다음 안내: 고객이 해야 할 일, 또는 회사가 할 일과 시점
4. 맺음말

**담당자 메모** (고객에게 보내지 않음)
- 문의 유형:
- 근거로 쓴 정책 문장:
- 확인이 필요한 것:

## 확인 기준
- 정책에 없는 약속(보상금, 쿠폰, 특정 날짜 보장)을 쓰지 않았는가
- 정책으로 답할 수 없는 부분은 "담당자 확인 후 안내드리겠습니다"로 썼는가
- 기간·금액 숫자가 policy.md와 정확히 같은가
- 문의에 없는 주문번호·상품명을 지어내지 않았는가
