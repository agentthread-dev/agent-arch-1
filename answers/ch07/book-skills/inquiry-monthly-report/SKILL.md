# 월간 고객 문의 분석 보고서

## 목적
팀장님이 3분 안에 이번 달 문의 흐름과 검토할 일을 파악하게 한다.

## 입력
- 유형별 건수: 이번 달과 지난달 (inquiry-classify의 유형 이름 그대로)
- 주요 문의 메모
- 지난달 건수가 없으면 지어내지 말고 표에 "확인 필요"로 둔다

## 절차
1. `assets/report-template.md`를 그대로 복사해 틀로 쓴다. 칸을 더하거나 빼지 않는다
2. `references/writing-rules.md`와 `references/examples.md`를 읽는다
3. 2번 표를 채운다. 증감 칸에는 결과와 계산식을 함께 쓴다
4. 3번 "눈에 띄는 변화"를 쓴다. 입력 메모에 있는 내용만 "확인된 사실"에, 사실끼리 원인으로 잇는 문장은 "가설"에 둔다
5. 4번 "검토 제안"을 쓴다. 제안마다 근거 사실을 하나씩 붙인다
6. 1번 "한눈에 보기" 3줄은 맨 마지막에 쓴다
7. 확인 기준으로 점검하고, 결과를 담당자 점검 메모에 적는다

## 확인 기준
- 각 유형의 증감 = 이번 달 − 지난달 이고, 계산식이 함께 적혀 있는가
- 표의 합계가 입력의 합계와 같은가 (다르면 표를 고치지 말고 "확인 필요"로 표시)
- "확인된 사실"의 문장마다 입력 메모에 근거가 있는가
- "때문이다", "원인은" 같은 단정이 가설에 쓰이지 않았는가
- 제안이 지시형("~해야 한다")이 아니라 "검토 제안"으로 쓰였는가
