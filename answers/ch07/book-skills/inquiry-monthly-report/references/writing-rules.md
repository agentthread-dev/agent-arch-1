# 보고서 작성 요령

## 숫자
- "크게", "많이" 대신 숫자로 쓴다: "11건에서 18건으로 7건 늘었다"
- 증감은 "이번 달 − 지난달"로 계산하고, 표에 계산식을 함께 쓴다: +7 (18−11)
- 비율(%)은 입력에 있는 숫자로 계산할 수 있을 때만 쓴다

## 사실과 가설
- 입력 메모에 사실로 적힌 사건·수치 = 확인된 사실 (메모 속 추측·전언은 사실이 아니다)
- 두 사실을 원인과 결과로 잇는 문장 = 가설. "가설 (확인 필요)" 아래에 쓴다
- "때문이다", "원인은" 같은 단정 표현은 확인된 사실에만 쓴다

## 제안
- 지시하지 않는다: "고쳐야 한다" (X) → "검토해 볼 수 있다(검토 제안)" (O)
- 제안 하나에 근거가 된 사실 하나를 함께 적는다
