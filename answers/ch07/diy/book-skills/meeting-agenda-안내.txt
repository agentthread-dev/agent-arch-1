[meeting-agenda 사용 안내]
무엇을 하나 : 지난주 회의록 + 이번 주 안건 메모 → 60분 주간 팀 회의 안건지
먼저 필요한 것 : 지난주 회의록("결정 필요" 항목이 적힌 것), 이번 주 안건 메모
설치        : meeting-agenda 폴더째 ZIP으로 압축(폴더 안의 파일이 아니라 폴더 자체)
              → Claude Desktop 설정 → 사용자 지정 → Skills → 추가 → Skill 업로드 → meeting-agenda.zip
              → 목록에서 meeting-agenda가 켜져 있는지 확인
요청 예     : "지난주 회의록이랑 이번 주 안건 메모로 회의 안건지 만들어 줘" + 두 파일 첨부
꼭 볼 것    : 작성자 점검 메모(시간 합계, "결정 필요" 항목 수, "담당 미정" 안건)를 확인하고 지운 뒤 공유
바꾸려면    : 안건지 모양 → assets/agenda-template.md / 쓰는 요령 → references/writing-rules.md
              회의 시간이 60분이 아니면 요청에 "회의 시간 45분"처럼 적는다
