# 고객 문의 유형 분류

## 목적
고객 문의 묶음을 정해진 유형으로 나누고 건수를 세어, 담당자가 무엇이 많은지 한눈에 보게 한다.

## 입력
- 고객 문의 여러 건 (파일 여러 개 또는 한 파일에 여러 건)

## 절차
1. `references/categories.md`를 읽고 유형 네 개와 "판단 필요" 규칙을 확인한다
2. 문의마다 번호를 붙이고, 한 줄로 요약한다
3. 문의 원문에서 유형의 근거가 되는 말을 찾아 유형을 정한다
4. 분류표 아래에 유형별 건수를 센다
5. 확인 기준으로 점검하고 결과를 적는다

## 출력 형식
| 번호 | 요약 | 유형 | 근거 단어 |
|---|---|---|---|

유형별 건수: 배송 _ / 교환·반품 _ / 환불 _ / 기타 _ / 판단 필요 _ / **합계 _**

## 확인 기준
- 입력된 문의가 표에 정확히 한 번씩 나오는가 (합계 = 입력 건수)
- 유형 칸에 categories.md의 네 유형과 "판단 필요" 외의 말이 없는가
- 근거 단어는 문의 원문에 실제로 있는 말인가
- 두 유형에 걸치는 문의를 한쪽으로 정해 버리지 않았는가 ("판단 필요"로 둠)
