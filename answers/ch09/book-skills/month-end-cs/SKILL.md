# 월말 고객 응대 흐름

이 Skill은 일을 직접 하지 않고, 아래 Skill들을 정해진 순서로 사용한다.

## 입력
- 이번 달 고객 문의 묶음
- 지난달 유형별 건수 (없으면 보고서의 지난달 칸은 "확인 필요")

## 순서
1. **분류**: inquiry-classify Skill의 절차대로 이번 달 문의를 분류한다
2. **중간 점검 1**: 분류 합계 = 입력 문의 수 인가? 다르면 여기서 멈추고, 빠지거나 겹친 문의 번호를 알려 준다
3. **보고서**: 대상 월, 분류표의 유형별 건수("이번 달"), 지난달 유형별 건수, 분류표의 문의 요약을 함께 넘겨 inquiry-monthly-report Skill의 절차대로 보고서를 쓴다. 문의 요약이 보고서의 "주요 문의 메모" 역할을 한다
4. **중간 점검 2**: 보고서 표의 이번 달 숫자가 분류표 건수와 하나도 빠짐없이 같은가? 다르면 보고서를 한 번 고치고 다시 점검한다. 그래도 다르면 여기서 멈추고 다른 칸을 알려 준다
5. **답장**: 분류에서 "판단 필요"인 문의만 골라, 문의마다 customer-reply Skill의 절차대로 답장 초안을 쓴다
6. **마감 요약**: 맨 끝에 아래 형식으로 정리한다

## 마감 요약 형식
- 분류: 총 _건 (중간 점검 1 통과/중단)
- 보고서: 작성 완료 (중간 점검 2 통과/중단, 고친 적 있음/없음)
- 답장 초안: _건 (문의 번호: _)
- 사람이 확인할 것: 보고서의 "가설", 답장 초안의 "담당자 확인 필요" 항목
