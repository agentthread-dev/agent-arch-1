[문의함 서버 안내판 — 설계 초안]
도구
- list_inquiries   : 기간을 받아 문의 목록(번호·제목·받은 날)을 돌려준다.
                     문의를 고르거나 셀 때 쓴다. 내용은 돌려주지 않는다.
                     입력 month(필수, 예 2026-11)            / 읽기 / 항상 허용
- read_inquiry     : 문의 번호 하나의 전문을 돌려준다. 답장을 쓰거나 분류할 때 쓴다.
                     입력 id(필수)                            / 읽기 / 승인 필요
- save_reply_draft : 문의 번호에 답장 초안을 저장한다. 고객에게 보내지는 않는다.
                     입력 id(필수), text(필수)                / 바꾸기 / 승인 필요
(보내기 도구는 일부러 만들지 않음 — 보내기는 사람이 한다)
리소스  : 응대 정책 문서 (5장 policy.md와 같은 내용)
프롬프트: "이번 달 문의 마감" — 9장 month-end-cs Skill을 부르는 요청 틀
